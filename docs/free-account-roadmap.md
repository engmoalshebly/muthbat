# خطة دفتر الحساب المتكامل

لا تعني هذه القائمة أن الميزات منشورة أو مكتملة.

- [ ] حسابات أشخاص مستقلة دون عملية، رصيد افتتاحي واتجاهات واضحة.
- [ ] سجل شامل مع بحث وتصفية وفترات ورصيد متسلسل.
- [ ] تاريخ العملية وتصنيفات محفوظة ومتوافقة مع النسخ القديمة.
- [ ] تقارير شهرية وتصنيفات، فصل العملات وعدم جمعها دون تحويل صريح.
- [ ] تصدير CSV وPDF حسب الفترة.
- [ ] دفاتر متعددة وأرشفة الحسابات دون حذف القيود.
- [ ] تصحيح موثق للقيود دون إعادة زر العكس المحذوف من القائمة.
- [ ] عمليات دورية وتذكيرات محلية مع منع الإنشاء المكرر.
- [ ] قفل بالبصمة ونسخ احتياطية مشفرة واستعادة على جهاز ثان.
- [ ] Google Drive اختياري: إعداد OAuth وموافقة المستخدم وتجربة استرجاع.
- [ ] مزامنة سحابية اختيارية مع اختبار التعارض والعزل وإعادة المحاولة.

## شروط التسليم

اختبار كل ميزة، الحفاظ على البيانات القديمة، وعدم إظهار نجاح مزامنة غير مؤكد.
التحقق من عقد نقل الدفتر للسحابة قبل نقل حقول جديدة مثل التصنيف؛ لا يُسمح بفقدها بصمت.
