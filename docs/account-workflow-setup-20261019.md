# تجهيز التطبيق من البداية

## ما جُهز

نتيجة التشغيل في هذه الجلسة: نجح بناء APK الاختباري، ونجحت 39 حالة Flutter والتحليل الساكن. نجح فحص عقد SQL في قاعدة PostgreSQL المحلية. فحص الخادم السحابي محجوب بصلاحية 403 ولم ينفذ نشر أو تثبيت على الهاتف.

- إعداد سحابي موجود للمشروع sgnbtrcbllnffcyzsjei، موسوم APP_ENV=staging وPHONE_VERIFICATION_ENABLED=false.
- سكربت mobile/tool/prepare-account-workflow.ps1 يفحص الإعدادات، ويجلب الاعتماديات المقيدة، ويحلل المسارات المعدلة، ويشغل اختبارات الحساب والمزامنة، ويمكنه بناء APK اختباري.
- سكربت debt-ledger-supabase/tools/deploy-account-workflow.ps1 يراجع الترحيلات قبل نشرها، ثم يتحقق من عقد الدوال وينشر customer-directory وcustomer-contacts وlocal-notebook-import. لا يعدل إعدادات Auth أو يستبدل الأسرار أو يحذف بيانات المستخدمين.
- فحص SQL للقراءة فقط tools/verify-account-contract.sql يتحقق من وجود الدوال المطلوبة وعدم إتاحتها للزائر المجهول أو كشف دالة قراءة الهاتف الخاصة للتطبيق مباشرة.

## التجهيز المحلي

من D:\Dafter\mobile:

```powershell
.\tool\prepare-account-workflow.ps1
.\tool\prepare-account-workflow.ps1 -BuildApk
```

نسخة الاختبار: mobile/build/app/outputs/flutter-apk/app-debug.apk. هذه نسخة Debug وليست إصدار متجر موقّعًا. ملف android/key.properties غير موجود؛ يتطلب إصدار المتجر مفتاح التوقيع المعتمد، دون إنشاء بديل قد يمنع تحديث تثبيت قديم.

## إكمال الخادم

محاولتا migration list وdb query رفضتا بصلاحية 403. لا يوجد إثبات في هذه الخطوة على تطبيق آخر ترحيلات الحساب في السحابة. أعد تسجيل Supabase CLI بحساب أو رمز له صلاحية المشروع، دون إرسال الرمز داخل المحادثة:

```powershell
supabase login
```

ثم من D:\Dafter\debt-ledger-supabase:

```powershell
.\tools\deploy-account-workflow.ps1 -ProjectRef sgnbtrcbllnffcyzsjei -CheckOnly
.\tools\deploy-account-workflow.ps1 -ProjectRef sgnbtrcbllnffcyzsjei
```

الترحيلات الجديدة المطلوبة تشمل 20261019152511 و20261019153708 و20261019160056، بالترتيب، مع سائر ترحيلات المشروع السابقة. يجب بقاء مفاتيح تشفير الهاتف الحالية وأي إصدارات سابقة مستخدمة؛ لا تستبدلها أثناء التجهيز.

بعد نجاح نشر العقد، شغّل التحقق من D:\Dafter\mobile:

```powershell
.\tool\prepare-account-workflow.ps1 -VerifyCloud
.\tool\run-cloud.ps1 -DeviceId R3CNC05M1LW
```

## اختبار البداية إلى النهاية

1. افتح حساب الاختبار، وأنشئ عميلًا، وسجل دينًا له، ثم انتظر تأكيد المزامنة.
2. افصل الاتصال، وسجل سدادًا وعدّل الاسم؛ تحقق من تغير العرض المحلي، ثم أغلق التطبيق وافتحه وتحقق من بقاء البيانات.
3. أعد الاتصال؛ تحقق من الرصيد النهائي وعدم تكرار العميل أو القيد.
4. افتح الحساب على جهاز مصرح آخر؛ تحقق من الاسم والهاتف والقيود والرصيد.
5. غيّر حالة قيد قديم أو اعكسه؛ تحقق من وصول الحالة والرصيد إلى الجهاز الآخر.
6. أرشف العميل؛ تحقق من اختفائه من القائمة النشطة على الجهازين وبقاء القيود محفوظة.

التجهيز لا يمسح الدفاتر السابقة أو الطابور أو حسابات المستخدمين. لا تعتبر اختبار السحابة ناجحًا قبل استعادة الصلاحية وفحص العقد المنشور.
