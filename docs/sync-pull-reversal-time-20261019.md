# إصلاح نتيجة المزامنة وتاريخ العكس المستورد

التاريخ: 2026-10-19

## المزامنة

فشل سحب دليل العملات أو الأنشطة أو العملاء أو القيود أو أرصدة العملات أو النزاعات ينتقل إلى دورة المزامنة بدل الاكتفاء بتسجيله. تُعرض حالة الخطأ، ولا يتغير وقت آخر مزامنة ناجحة. يبقى التقدم المحلي المحفوظ متاحًا، ويمكن للجولة التالية استكمال السحب.

يعيد `triggerSync()` قيمة `true` فقط بعد اكتمال السحب المطلوب وعدم وجود عمليات معلقة أو عمليات تحتاج مراجعة. تستخدم مهمة الخلفية هذه النتيجة لطلب إعادة المحاولة عند الفشل. وقت آخر نجاح لا يتقدم لمجرد نجاح السحب مع بقاء أوامر غير مرسلة.

تبقى قراءة/كتابة مرآة مؤشر المزامنة على الخادم اختيارية؛ المؤشر المحلي هو المرجع الملزم. يوجد اختبار يثبت أن تعطل المرآة وحدها لا يفشل سحب البيانات المكتمل.

## تاريخ العكس

يضيف الترحيل `20261019054323_preserve_imported_reversal_time.sql` تنفيذًا داخليًا للعكس يقبل تاريخ الحدث. يستخدم مستورد الدفتر `occurred_at` الأصلي، ويرفض غياب التاريخ أو القيم الزمنية غير المنتهية. يحتفظ السجل بـ `created_at` وقت الاستيراد لضمان ظهوره في السحب التزايدي.

واجهة العكس المعتادة ومسار معالجة الاعتراضات يحتفظان بتوقيتهما الصادر من الخادم وبالتوقيع الحالي للدالة، وفحوص العضوية والأرصدة حسب العملة وترتيب الأقفال ومنع التكرار. لا تمنح دالة التاريخ الداخلية صلاحية التنفيذ للمستخدم أو لدور الخدمة.

يُنشأ قيد اليومية من التاريخ الأصلي داخل المعاملة نفسها، دون تعديل سجل مالي بعد إنشائه. التغيير لا يعيد كتابة تواريخ السجلات التي استُوردت سابقًا.

ارتفع عقد الاستيراد إلى الإصدار 5. يتحقق التطبيق منه ومن جاهزية وظيفة النقل قبل تجميد دفتر جديد؛ يلزم نشر الترحيل قبل إصدار التطبيق المعدل. لا يوجد نشر إلى الإنتاج ضمن هذا العمل.

## التحقق

نجحت الاختبارات الـ18 في ملفات Dart الأربعة، ونجح اختبارا SQL بعد تطبيق جميع ترحيلات التطبيق على قاعدة جديدة.

- `test/sync_pull_failure_test.dart`: أعطال مراحل السحب الست، الاحتفاظ بوقت النجاح السابق، غياب وقت النجاح عند الفشل الأول، التعافي، بقاء الأوامر غير المرسلة، وفشل مرآة المؤشر الاختيارية.
- اختبارات قبول المزامنة دون اتصال وعزل التخزين واختيار النشاط المستورد.
- `tools/test-imported-reversal-time.sql`: حفظ اللحظة الأصلية مع فرق التوقيت، تاريخ اليومية المحلي، وقت الإنشاء، منع التكرار، توقيت العكس العادي، حجب دالة التاريخ الداخلية، والتراجع الذري للتواريخ المفقودة/غير الصالحة.
- إعادة اختبار `tools/test-local-notebook-contacts.sql` لضمان استمرار نقل الاتصال والوصف والاستئناف.
- تحليل ملفات Dart المعدلة بلا أخطاء أو تحذيرات؛ أربع ملاحظات info سابقة باقية في شاشة الدفتر.

اختبارات SQL تعمل على PostgreSQL 16 معزول مع بدائل محلية لواجهات Auth/Storage وcron، ولا تمثل تجربة حية لبوابة Supabase أو الخدمة المنشورة.
