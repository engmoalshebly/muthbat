# مُثبَت | Muthbat

منصة وتطبيق لإدارة وتوثيق حسابات العملاء والديون والمدفوعات، مع دعم العمل المحلي والمزامنة عند توفر الاتصال.

## مكونات المشروع

- `mobile`: تطبيق Flutter للهواتف.
- `debt-ledger-supabase`: مخطط قاعدة البيانات والترحيلات وخدمات Supabase.
- `OpenWA`: خدمة تكامل WhatsApp لإرسال رموز التحقق.

## تنبيه

قيم الاتصال ومفاتيح الخدمات لا تُحفظ داخل المستودع. استخدم ملفات البيئة المحلية أو أسرار بيئة النشر.
