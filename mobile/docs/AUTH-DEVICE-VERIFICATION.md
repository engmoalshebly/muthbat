# تحقق تعارض المصادقة على جهاز Android

نُفذ على هاتف Samsung SM N986U، Android 12 / API 31، بتاريخ 18 أكتوبر 2026.

استُخدم اختبار تكامل `integration_test/auth_race_device_test.dart` ونسخة مستقلة بمعرّف `com.muthbat.muthbat.auth_operational_test`. لم تُستخدم بيانات دخول فعلية أو حسابات سحابية: استجابات HTTP محاكاة داخل عملية التطبيق. قاعدة SQLCipher والتخزين الآمن يعملان بإضافاتهما الأصلية على الهاتف؛ لم يُستبدلا بمخازن ذاكرة. لا يغيّر الاختبار اتصال الهاتف أو سرعة الشبكة لبقية تطبيقاته.

## النتائج

- أُوقف رد الملف للحساب «أ» حتى اكتمل دخول «ب»، ثم أُطلق الرد القديم. أعادت محاولة «أ» فشلًا وبقيت هوية «ب» واسمه وحالة المصادقة وقاعدة حسابه كما هي.
- استُدعي الخروج مرتين دون انتظار؛ نجحت النتيجتان وبقي الحساب المحلي مقفلًا والحالة غير مصادق عليها. تحققت قراءة مخزن الجلسة من عدم وجود جلسة بعد الخروج.
- أُعيد الدخول، ثم أُنشئ متحكم يستعيد الحساب مع تعليق رد الملف تسع ثوانٍ. ظهر انتهاء مهلة الطلب بعد ثماني ثوانٍ كما هو متوقع. أُبطل التهيئة بـ`reset()` وأُطلق الرد، ولم تُعد المصادقة بعد انتظار اكتمال التهيئة.
- نجح الاختبار النهائي: `All tests passed` خلال 16 ثانية بعد البناء والتثبيت. نجح `flutter analyze --no-pub` دون ملاحظات.

كشف إعداد السيناريو ضرورة حماية محاولة الدخول الخارجية أيضًا، وليس تحميل الملف وحده. أضيف `_loginRequest` ليمنع استمرار النجاح أو نشر خطأ محاولة قديمة فوق محاولة أحدث، ويُبطل عند الخروج أو reset.

## إعادة التشغيل

من مجلد `mobile` في PowerShell، بعد تجهيز الاعتمادات:

```powershell
$env:ORG_GRADLE_PROJECT_authOperationalTest='true'
flutter test integration_test/auth_race_device_test.dart -d <android-device-id> --no-pub
Remove-Item Env:ORG_GRADLE_PROJECT_authOperationalTest
```

خاصية Gradle تؤثر في نسخة debug فقط؛ لا تغيّر معرّف نسخة الإنتاج. احرص على تفعيلها لهذا الاختبار لعزل بياناته عن التطبيق المعتاد. تظل النسخة التجريبية على الجهاز، ولم يُحذف التطبيق المعتاد أو تُمسح بياناته.

## حدود ما أُثبت

هذا اختبار تشغيل فعلي لمتحكم المصادقة والتخزين على الهاتف مع تأخير HTTP متحكم به. لا يمثل اختبارًا يدويًا كاملًا لواجهات الدخول وشاشة البداية، ولا اختبار ضغط شبكة حقيقية أو تجديد JWT لدى Supabase أو إلغاء عضوية على الخادم. لم تُختبر iOS أو سيناريوهات إيقاف العملية قسرًا. يحتاج الاعتماد النهائي هذه السيناريوهات حسب منصات الإصدار؛ النتيجة هنا تغطي ترتيب الردود المتأخرة والتبديل والخروج والإبطال المحددة أعلاه.
