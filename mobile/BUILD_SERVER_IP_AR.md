# بناء Android محليًا لخادم الاختبار

البناء يتم على Windows، وليس على الخادم. شغّل من مجلد `mobile`:

```powershell
$env:SUPABASE_ANON_KEY = '<مفتاح anon العام للخادم>'
.\tool\build-server-ip.ps1
```

السكربت يمرر `SUPABASE_URL=http://217.216.79.195:55321` و`APP_ENV=prod`، وينتج `build/app/outputs/flutter-apk/muthbat-server-ip.apk` عند النجاح فقط.

هذه نسخة اختبار: الاتصال HTTP غير مشفر، وتوقيع Release الحالي يستخدم مفتاح التطوير. لا تستخدم كلمات مرور أو بيانات مالية حقيقية قبل HTTPS وتوقيع إصدار مناسب. وسم prod لا يحل هذين القيدين.

التطبيق يتصل بـ Supabase. إرسال OTP يتم من وظيفة الخادم إلى OpenWA، وليس باستخدام مفتاح OpenWA داخل التطبيق. يلزم اتصال جلسة WhatsApp وضبط أسرار الوظيفة على الخادم؛ استجابة فحص الصحة وحدها لا تثبت نجاح إرسال OTP.

لا تضع SERVICE_ROLE_KEY أو أسرار OpenWA في إعدادات بناء التطبيق. لا يلزم أن يكون الهاتف على الشبكة المحلية نفسها إذا كان الخادم العام متاحًا.
